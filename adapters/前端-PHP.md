# PHP 应用取证提示

先按实际职责识别 PHP 的页面渲染、请求处理、数据访问或后台任务角色，再定位路由、模板、导航、表单、命令或其他入口。页面链路继续追 JavaScript 事件、表单提交、控制器或模板处理及用户反馈；服务链路追参数、校验、状态写入和失败。PHP 可以直接处理业务，也可以调用其他语言服务；不要预设另一侧语言或仅凭 URL、方法名相似认定跨仓关联。

权限显示、动态菜单、会话变量和服务端权限校验分开记录。若配置、部署路由或运行期菜单不可见，标记为未证实；不能把“代码中有页面”写成“所有用户都能看到”。

记录表单或请求字段、提交方式、PHP 控制器／模板函数、客户端调用及服务契约之间的有据映射。PHP 方法按实际仓库和职责进入方法索引；页面服务器返回与其他服务响应分别取证。跨层、异步或外部依赖问题按需读取[跨语言场景取证](../skills/extract-app-knowledge/references/跨语言场景取证.md)。
