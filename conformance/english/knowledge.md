# Order lookup

## Applicability

Only signed-in users can look up orders in their assigned regions.

## Q: Can I look up any order?

You can look up an existing order only when its region is assigned to you. Being signed in alone does not grant access to every order.

## Branches and failures

Signed-out users receive a sign-in-required result. Missing orders return a not-found result. Orders outside assigned regions return an outside-region result.

## Unverified outcomes

Actual region assignments and production behavior have not been verified. Do not infer that any particular account can access an order.
