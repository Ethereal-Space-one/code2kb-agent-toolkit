# 复杂步骤回归：合成重量档，不对应生产业务

这是无状态的 Python 演练。用两个原本相接的档位，验证「调整了三个字段」不能替代三条计算；规则和返回类别仅适用于本样例。

## 临时档如何调整和匹配

调档系数 d 不大于 0 时，整个档位保留原值。d 大于 0 时，三个字段都从原档读取，不写回原档。

| 字段 | 条件和计算 | 否则 | 如何消费 |
| --- | --- | --- | --- |
| 小端 | 小端大于 0 时，小端加 d | 保留小端原值 | 作为匹配下界 |
| 估重 | 估重不大于 7 时，估重加 2d | 保留估重原值 | 不参与区间匹配 |
| 大端 | 大端至少为 5 时，大端减 d | 保留大端原值 | 作为匹配上界 |

匹配区间左开右闭。当前档不命中且重量不大于其小端时，向后取档；这个结果不是区间命中。走完仍未返回则为超最大档。原档相接不代表临时档相接：d 等于 1 时，小档 (0, 4]，大档 (6, 9]，重量 5 向后取大档；6 等于下一档下界，仍不是区间命中。正式配置实值未证实，本例不验证生产运行。

开发验证：从项目根目录运行 `python3 -m unittest discover -s validation/tests -p test_field_transform.py`。正例经实际发布、审计和检索；反例也经相同结构检查，但专题验收不能通过。案例不运行回答模型。
