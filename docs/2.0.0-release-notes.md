# Code2KB Agent Toolkit 2.0.0

把源码和这套工具交给 AI 编码助手，提取业务规则与实现依据，生成供机器人检索问答使用的知识文件。

## 本次变化

- **统一为 Agent Toolkit**：产品、仓库与 Python 分发包更名，CLI 仍为 `code2kb`；新发布物的生成者为 `Code2KB Agent Toolkit`。
- **重写中英文首页与指南**：说明输入、知识产物、适用用户、审核选择及操作手顺；配图同步更新。
- 包含此前主分支的全栈盘点、跨语言场景取证和可选英文知识输出补充；独立验证、检索与审核能力延续现有流程。

## 破坏性变更与旧项目

2.0 不提供旧名称兼容或自动迁移。新工具不审计、也不直接覆盖旧品牌发布快照；请保留原项目及其 Git 历史，使用生成时对应的工具审计。

已有知识可在新的知识 Git 项目中复用配置、知识源及所需审核材料，经检查后按正常审核与发布流程交付；不要复制旧发布目录或修改其清单身份。知识源格式、事实 ID 和文件协议保持不变，无须仅为品牌变化重写业务正文。

若同一环境装过旧包，先卸载 `code2kb-spec`，或使用全新虚拟环境。仓库提供源码安装入口，未上传 PyPI 包：

```bash
git clone --branch v2.0.0 https://github.com/Ethereal-Space-one/code2kb-agent-toolkit.git
cd code2kb-agent-toolkit
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -e .
code2kb --version
```

## 验证与边界

Python 3.9–3.13 CI 覆盖单元测试、规范与一致性夹具、检索结构、示例、安装、链接及公开内容检查。新包在源码目录外完成版本查询、发布与审计验证；旧品牌快照拒绝后内容不变，历史标签与冻结夹具保留原样。

使用者仍需提供 AI 编码助手、问答模型、FTS／向量索引和机器人部署。更名不会自动更新已有知识库或索引；静态源码取证不等于线上验证，结构检查不证明自然语言结论正确。详见[使用指南](usage.md)和[兼容性说明](compatibility.md)。

## English

Code2KB Agent Toolkit turns pinned source evidence into business and engineering knowledge for retrieval-based Q&A. The repository and Python distribution are now `code2kb-agent-toolkit`; the CLI remains `code2kb`.

**Breaking change:** old-brand release snapshots must be audited with their original tool version. Reuse checked sources and required review materials in a new knowledge Git project; do not copy or relabel old release artifacts. No old-name compatibility or automatic migration is provided. The knowledge-source format is unchanged. Your agent, retrieval service and bot deployment remain external. See the [English guide](usage.en.md).
