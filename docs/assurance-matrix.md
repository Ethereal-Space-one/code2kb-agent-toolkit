# 规范要求的实际保证范围

本表对应当前 62 条 `C2KB-*` 要求。**机器**表示参考实现会检查给定输入的结构、路径、摘要或状态；**记录**表示工具要求存在自填记录，不能证明记录内容真实；**流程**表示需要使用方、审核人或 Consumer 执行的约束。一个要求可能兼有多种成分，表中列的是最容易被误读为“已验证”的关键边界。第三方实现应另行声明自己的覆盖，不得直接继承参考实现的保证。

| 要求 ID | 主要保证 | 不能据此推断 |
| --- | --- | --- |
| C2KB-BASE-001 | 机器 | 协议标识可读不表示项目内容正确 |
| C2KB-BASE-002 | 记录 | 三种版本字段存在不表示部署同步 |
| C2KB-BASE-003 | 机器 | 固定提交与锚点存在不表示结论被源码蕴含 |
| C2KB-BASE-004 | 流程 | 工具不能认证自然语言与现实身份 |
| C2KB-BASE-005 | 流程 | 扩展的外部语义仍须独立核对 |
| C2KB-CONSISTENCY-001 | 记录 | 大纲和已启用 Adapter 的对账不能证明所有动态入口穷尽 |
| C2KB-CONSISTENCY-002 | 记录 | 四类自测的“通过”由作者填写，工具不运行问答模型 |
| C2KB-CONSISTENCY-003 | 机器 | 影响队列只覆盖已登记的影响关系 |
| C2KB-CONSISTENCY-004 | 记录 | 已发现路径的语义闭环不证明没有漏发现路径 |
| C2KB-CONSISTENCY-005 | 记录 | 已登记配置键不证明运行值或服务端规则 |
| C2KB-CONSISTENCY-006 | 流程 | 正文条件和聚合语义需要人或独立复核者判断 |
| C2KB-CONSISTENCY-007 | 流程 | Validator 不证明自然语言语义正确 |
| C2KB-EVIDENCE-001 | 记录 | 单一结论及条件的语义由作者编写 |
| C2KB-EVIDENCE-002 | 机器 | 锚点可解析和行号存在不表示结论成立 |
| C2KB-EVIDENCE-003 | 流程 | 推断和未知是否被正文写成事实需语义复核 |
| C2KB-EVIDENCE-004 | 机器 | 证据类型、模块、事实与有效期可核对，观测真实性不可核对 |
| C2KB-EVIDENCE-005 | 记录 | 来源标题、定位、摘要和脱敏声明由生产者提供 |
| C2KB-EVIDENCE-006 | 机器 | 意图与证据和行为事实的引用闭环不证明业务原因真实 |
| C2KB-EVIDENCE-007 | 机器 | 发布范围按已登记等级控制，等级本身仍需核实 |
| C2KB-EVIDENCE-008 | 机器 | 双向引用一致不证明正文与事实语义相同 |
| C2KB-EVIDENCE-009 | 机器 | UTC 日期内有效不证明观测在当前线上仍适用 |
| C2KB-EVIDENCE-010 | 机器 | 逐项处置已登记入口不证明盘点穷尽或事实关联正确 |
| C2KB-EXT-001 | 机器 | 适配器输出格式有效不证明候选关系正确 |
| C2KB-EXT-002 | 记录 | 缺口登记依赖使用方识别适配器未覆盖范围 |
| C2KB-EXT-003 | 机器 | 外部报告身份、路径和摘要匹配不证明报告判断真实 |
| C2KB-EXT-004 | 机器 | 外部检查不能使用内置检查 ID |
| C2KB-EXT-005 | 机器 | 敏感模式扫描只覆盖配置和内置模式 |
| C2KB-EXT-006 | 流程 | 第三方兼容声明由实现者负责真实性 |
| C2KB-META-001 | 机器 | JSON 结构有效不证明字段对应真实系统 |
| C2KB-META-002 | 机器 | 协议版本受支持不表示当前知识已审核 |
| C2KB-META-003 | 机器 | 仓库和提交可访问不表示它们是生产部署版本 |
| C2KB-META-004 | 机器 | 环境变量安全解析不证明指向正确仓库 |
| C2KB-META-005 | 机器 | 提交不可变不证明来源范围完整 |
| C2KB-META-006 | 机器 | 两套审核字段互斥不认证实际审核人 |
| C2KB-META-007 | 记录 | 审核身份、日期和策略所有者为声明字段 |
| C2KB-PROJECT-001 | 机器 | 有独立 Git 历史不代表托管分支受保护 |
| C2KB-PROJECT-002 | 机器 | 路径与符号链接边界不证明内容可信 |
| C2KB-PROJECT-003 | 记录 | 大纲逐项登记不证明范围外入口未漏报 |
| C2KB-PROJECT-004 | 机器 | 稳定 module_id 不证明模块划分合理 |
| C2KB-PROJECT-005 | 机器 | 双版路径隔离不等于敏感规则可对外披露 |
| C2KB-PROJECT-006 | 机器 | 历史快照可恢复不保证可信历史未被整体重写 |
| C2KB-RELEASE-001 | 机器 | Git HEAD 内容一致不认证提交者身份 |
| C2KB-RELEASE-002 | 机器 | 清单摘要可复核不证明源事实真实 |
| C2KB-RELEASE-003 | 机器 | 当前指针一致不证明消费者已切换索引 |
| C2KB-RELEASE-004 | 机器 | 本地失败恢复不覆盖外部消费者的状态 |
| C2KB-RELEASE-005 | 机器 | 纯产物审计证明内部一致性，不证明发布者可信 |
| C2KB-REVIEW-001 | 记录 | 人工批准命令不认证现实审核人 |
| C2KB-REVIEW-002 | 流程 | 不得冒充人工批准须由使用方执行 |
| C2KB-REVIEW-003 | 机器 | 策略与 Git HEAD 相同不证明策略由授权人批准 |
| C2KB-REVIEW-004 | 机器 | 新报告的候选身份与摘要匹配不证明外部检查结论正确 |
| C2KB-REVIEW-005 | 机器 | 风险与发现门禁依据执行者填报，未检测未报风险 |
| C2KB-REVIEW-006 | 流程 | 自然语言报告真实性不在工具保证范围 |
| C2KB-ROLE-001 | 流程 | 角色声明不认证执行者 |
| C2KB-ROLE-002 | 流程 | Producer 与 Reviewer 的现实隔离需要外部权限控制 |
| C2KB-ROLE-003 | 记录 | 两个身份字符串不相同不证明是不同的人 |
| C2KB-ROLE-004 | 流程 | Consumer 的实际目录权限需在部署端配置 |
| C2KB-VIEW-001 | 机器 | 共有正文逐字一致不证明语义正确 |
| C2KB-VIEW-002 | 机器 | 模式扫描只能拦截已识别的技术/过程表达，不能判断披露许可 |
| C2KB-VIEW-003 | 机器 | 过程文件不入检索目录不保证外部导入器配置正确 |
| C2KB-VIEW-004 | 机器 | 研发事实 ID 可定位不证明引用恰当 |
| C2KB-VIEW-005 | 流程 | 发布索引不得单独承载结论仍需内容审阅 |
| C2KB-VIEW-006 | 机器 | 目录内链接可解析不保证外部网页可用 |

`CODE_VERIFIED` 是知识事实的证据等级名称，含义是“固定源码提交直接提供依据”；参考 Validator 实际检查的是仓库、路径和行号可解析，**没有执行源码对自然语言结论的蕴含判断**。同样，`confirm-claims` 和四类问答自测记录复核结果，不运行独立模型。对外说明工具能力时应使用本表的限定语。
