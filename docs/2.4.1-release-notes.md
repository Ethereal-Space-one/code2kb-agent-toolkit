# Code2KB Agent Toolkit 2.4.1：一次打包，两个发布端核对同一份文件

**已有 2.4.0 知识项目无需迁移，也不用重新发布。** 这次补丁改的是工具包如何到达使用者手里，不是知识文件、命令、审核或检索行为。

## 如何取用与核对

- Claude Code、Codex：从本版 GitHub Release 选择对应的 ZIP。
- DSH：在已发布后指定 `npm install code2kb-dsh@2.4.1`，或取 GitHub Release 的 `code2kb-dsh-2.4.1.tgz`。两个来源应为同一份压缩文件。npm 的版号标签是 `release-2.4.1`；发布过程不推进 `latest`。
- 验证下载：把三个归档、`release-manifest.json` 和 `SHA256SUMS.txt` 放在同一目录，运行 `sha256sum -c SHA256SUMS.txt`。清单列出源提交和每个归档的文件名、长度、SHA256 与 SHA512 integrity。自动生成的 GitHub 源码 ZIP/tar 不属于这五份附件。

维护者在同一受审提交上一次构建三个插件；npm 与 GitHub 独立下载并核对同一份构建产物。npm 只上传已校验的 DSH 包，不重新打包。GitHub 仅操作本次新建的草稿，核对五份附件的实际下载字节后才公开；两端的发布权限分开。碰到不一致、旧草稿或不确定的发布结果会停止，不覆盖历史版。只读演练用合成版本模拟上述交接，并不代替真实网站、权限与下载结果的核验。[维护者发行流程](release-process.md)

## English

Existing 2.4.0 knowledge projects need no migration or republication. This patch changes how the toolkit is distributed, not its commands, file format, review rules or retrieval behavior.

Select the Claude Code or Codex ZIP for your host. For DSH, after publication use `npm install code2kb-dsh@2.4.1` or download `code2kb-dsh-2.4.1.tgz` from the GitHub release. The two DSH archives should be byte-identical. The npm version-specific tag is `release-2.4.1`; this release does not advance `latest`.

The three plugin archives are built once. Each publisher checks the same build with separate credentials; the GitHub release adds `release-manifest.json` and `SHA256SUMS.txt`. Download all five files into one directory and run `sha256sum -c SHA256SUMS.txt` to verify them. The release workflow stops on conflicts or uncertain results rather than overwriting a past version. A synthetic, read-only rehearsal tests those paths without publishing.
