# 批次复核效率优化：实施与验收记录

日期：2026-11-09。状态：本地实现与验收完成；按授权作为 2.0 主分支补充进入 PR 与多版本 CI。原始标签不变。

## 已交付

- `preflight --project-root <project> --module-id <id>`：只读检查目标模块候选结构，复用正式 prepare 的候选集合、来源基线、目录、匹配表一致性和本模块链接规则。支持既有 full/compact、中文/英文和 `--files`；FAQ 使用既有解析器预览实际导航标题。
- 批次手顺：稳定输入上一份全局真实影响队列，逐模块实质复核、确认与准备，最终全局 check 成功且显式零待复核后不再逐模块索取空队列。输入变化作废旧结果。
- 可选滚动独审与接续：固定稿、实际消费者、单一写入者和单一检查点；不新增调度器或放宽 runner 的内置完成条件。
- 中英文说明与 README 短入口同步；补充具名盘点去向、未覆盖差集、原件引用及候选检索的实际可用边界。

预检不确认问答结果、自然语言真伪、跨模块一致性或批准；报告的 `not_checked` 明列未执行项。文本摘要不是全量冻结证书。正式 prepare 仍读取当前输入并执行全部门禁，不消费旧预检报告。缺失/过期的审核不能靠预检放行。

## 可重现的末次检查计时

测量脚本：[benchmark_batch_review.py](../scripts/benchmark_batch_review.py)。使用临时合成项目，复制公开测试夹具的结构；不读取真实业务项目。准备夹具不计时；只比较最终稳定零影响状态下的：

- repeated：逐模块 impact，再一次全局 check；
- batch：一次全局 check，要求显式 `pending_claim_impacts == 0`。

串行执行，三次交替顺序；每个规模的两条路径读取同一组输入，回放前后文件摘要不变，最终 check 完整输出一致。所有模块级 impact 均返回空队列。工具文件在回放前后也核对摘要。

| 合成模块数 | 命令次数 | repeated 中位数 | batch 中位数 | 两者各自范围 |
| --- | --- | --- | --- | --- |
| 12 | 13 → 1 | 1.690 秒 | 0.126 秒 | 1.683–1.707 / 0.126–0.132 秒 |
| 96 | 97 → 1 | 19.178 秒 | 0.197 秒 | 18.480–19.187 / 0.197–0.200 秒 |

- 12 模块 / repeated：1.707033、1.690214、1.682648 秒。
- 12 模块 / batch：0.125728、0.126198、0.132122 秒。
- 96 模块 / repeated：18.479868、19.177735、19.187123 秒。
- 96 模块 / batch：0.200138、0.197415、0.196798 秒。

环境：Python 3.9.6，Darwin arm64，单进程，无网络检索。基线 HEAD `8d54fe8fa9ebe60bcfcd68f5456634b62c60f7f8`，使用本次未提交实现；版本号未变。回放使用的 Python 文件摘要集合之 SHA-256 为 `5188a868cf77b186d39b9cc0b3a0bef41adc53d0ac7e27f71f2c1d9e7f44165e`。

复现命令：

```bash
python3 -B scripts/benchmark_batch_review.py --modules 12 96 --repetitions 3 --output /tmp/batch-review-results.json
```

输出保留每次命令、起止时间、退出码、耗时、最终检查和输入/工具摘要。不同机器、Git 夹具时间和临时目录会改变摘要与耗时，应比较同次回放的两条路径，不跨机器拼接数字。

**结论仅限减少重复末次检查。** 没有测量提取、作者写作、独审、返修、逐模块 confirm-claims/prepare 或发布的总工时；不得据此宣传端到端提速比例或真实大项目收益。
