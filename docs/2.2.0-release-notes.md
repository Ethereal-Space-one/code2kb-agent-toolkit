# Code2KB Agent Toolkit 2.2.0 插件分发

发布日期 2026-11-11。

把 Code2KB 安装到编码助手后，可以用同一套 Skill 盘点固定提交、提取业务规则和研发证据，审核后生成可供检索问答的业务版与研发版。插件内置 Python CLI，使用时需要 Git 和 Python 3.9+。现有知识项目可以直接使用原有文件。

- **DeepSeek Harness**：从 npm 安装 `code2kb-dsh`。
- **Claude Code**：使用发布 ZIP 启动 `claude --plugin-dir ./code2kb-claude-2.2.0.zip`，在会话中调用 `/code2kb:extract-app-knowledge`。
- **Codex**：在该版本的干净检出中运行 `codex plugin marketplace add .`，再运行 `codex plugin add code2kb@code2kb`。OpenAI ZIP 面向桌面执行环境。

三个插件包都从固定 Git 提交构建。npm 工作流检查标签、提交和 CI，再发布核验过的归档。

[插件安装与打包](https://github.com/Ethereal-Space-one/code2kb-agent-toolkit/blob/v2.2.0/docs/plugin-installation.md) · [兼容性](https://github.com/Ethereal-Space-one/code2kb-agent-toolkit/blob/v2.2.0/docs/compatibility.md)

## English

Code2KB 2.2.0 packages the shared extraction skill and CLI for DeepSeek Harness, Claude Code and Codex. Use the skill to turn pinned source into reviewed business and engineering knowledge that a search or Q&A system can index. The CLI requires Git and Python 3.9 or later. Existing knowledge projects can keep their files.

Install `code2kb-dsh` from npm for DeepSeek Harness, load the release ZIP with `claude --plugin-dir` for Claude Code, or add the repository marketplace from a clean tagged checkout for Codex. [English installation guide](https://github.com/Ethereal-Space-one/code2kb-agent-toolkit/blob/v2.2.0/docs/plugin-installation.md#english)
