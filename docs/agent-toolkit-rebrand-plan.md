## 名称与产品定位

| 对象 | 目标 |
| --- | --- |
| 产品展示名 | **Code2KB Agent Toolkit** |
| 图示短名 | **Code2KB** |
| 仓库名与 Python 分发包 | `code2kb-agent-toolkit` |
| CLI | `code2kb` |
| 工程版本 | `2.0.0` 待发布：停止审计旧品牌发布物，按破坏性变更处理 |
| 知识文件协议 | 保持 `c2kb-file/1`，仍读取 `0.8.3` 源文件 |

产品用于借助 AI 从源码提取业务与实现逻辑，生产供检索问答使用的知识文件。Skill 是 AI 入口，Spec 是文件规范，Prompt 是执行材料，CLI 提供校验和发布；不承诺模型托管、机器人部署或检索服务。SPEC.md 与 spec/ 保持为规范入口。

## 实施范围

1. 更新中英文首页、用户指南和品牌配图，先说明输入、产物、使用者和操作手顺；高级能力按需展开。
2. 统一仓库链接、包元数据、旧版构建入口和安装后的版本查询；新品牌在生成与审计中使用同一常量。
3. 审计只接受 Code2KB Agent Toolkit；旧品牌或未知生成者明确提示不支持，避免误报发布物已损坏。不新增别名包、双品牌接受分支或品牌迁移器。
4. 当前文档、示例、Issue 模板与包描述同步；历史设计、CHANGELOG、Release、标签和冻结夹具保留当时身份。历史说明不代表新工具兼容旧品牌发布物。
5. 完成本地验证后切换 GitHub 仓库名、About 和本地 remote；不覆盖历史 Release，也不向 PyPI 上传或声称已注册包名。

目标仓库查询未发现已有同名仓库；2026-11-05 查询 PyPI 的新旧包名均为 404。此查询不构成对包名的预留。

## 使用者须知

> 本项目由 Code2KB Spec 更名为 Code2KB Agent Toolkit。请按新版 README 获取和安装；命令仍为 code2kb。不提供旧名称兼容或自动迁移。旧版发布物请使用其生成时对应的工具审计，不要修改冻结清单中的身份。已有知识源可经检查后继续维护并重新发布，无须仅为品牌变化重写业务知识；旧品牌发布物依赖的检索扩展也需随新基础发布重新生成。更名不会自动更新机器人、索引或已有本地 clone 的 remote。

在同一环境中从源码安装过旧包时，先卸载 code2kb-spec，再从新目录安装本项目；两个分发包使用同一个 code2kb 命令，不应并装。也可使用全新虚拟环境。仓库提供的是源码安装入口，未发布 PyPI 安装包。

已有旧品牌发布目录时，新工具既不审计也不直接覆盖它。保留原项目及其 Git 历史供旧工具使用；在新的知识 Git 项目中复用配置、知识源及所需审核材料，检查输入并按现有候选、审核和提交规则发布。不要把旧发布目录一并复制到新项目，也不要手改旧清单身份。

维护已有知识项目时，先核对 Git、配置、范围、固定源码提交和审核状态；现有审核仍按原有摘要与证据规则检查。品牌变化本身不创造运行证据，也不替代知识内容的复核。
