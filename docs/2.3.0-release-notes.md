# Code2KB Agent Toolkit 2.3.0 检索诊断与出处定位

发布日期 2026-11-14。

- **检索评测**分别显示预期模块和目标单元的首命中排名、平均倒数排名和召回率。报告显示实际标注数，并逐题列出未命中的目标和必要短语。
- **出处定位**在 `retrieval-query` 中返回原文链接。出处可唯一定位时直达小节，其他情况打开文件。
- **上下文诊断**用只读 `retrieval-diagnose-context` 对照实际召回候选和送给模型的原文片段，指出证据在哪一步缺失。

升级后可直接使用现有知识项目。新评测 JSON 报告为 `0.2`，未测指标为 `null`。已有 `0.1` 报告仍可审计。

## English

Code2KB 2.3.0 reports module and target unit ranks separately. Evaluation reports show how many cases or phrases were measured and list missing targets for each case. `retrieval-query` links to the released source section when it can identify the heading, with a file link as the fallback. The read-only `retrieval-diagnose-context` command compares retrieved candidates with the excerpts sent to the model.

Existing knowledge projects can keep their files. New evaluation reports use JSON schema `0.2` and return `null` for unmeasured metrics. Reports using `0.1` remain auditable.
