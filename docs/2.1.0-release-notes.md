# Code2KB Agent Toolkit 2.1.0 问答用例维护

发布日期 2026-11-10。

首次建库时，可以从核实过的事实设计问题。收到实际错答时，沿着原问法和证据分别核查知识正文、检索与回答，定位修复位置，再把确认过的问题留下复测。现有项目可直接使用该手顺。 [问答用例维护](https://github.com/Ethereal-Space-one/code2kb-agent-toolkit/blob/v2.1.0/skills/extract-app-knowledge/references/知识写作与复核.md#问答用例维护)

Kit 复用模块「问答自测」、候选验证包和检索问题集。项目方维护真实问题、业务判定及线上复测结果。已修复错答用于检查复发，未参与修复的真实问题用于测评整体回答质量。 [公开受理与完成案例](https://github.com/Ethereal-Space-one/code2kb-agent-toolkit/blob/v2.1.0/conformance/full-stack/README.md#问答用例维护示例)

## 预检与固定读取补充

- `preflight` 提前检查调用匹配状态、接口覆盖和双方锚点，并拒绝指向未登记模块的引用。实际跨模块目标和部署证据由正式流程核查。
- 在同一命令内复用入口集合及固定文件读取。公开 UniApp 夹具的清单在 `check` 中由读取 2 次降为 1 次，在 `prepare --refresh` 中由读取 3 次、解析 2 次降为各 1 次。
- 修正预检与正式流程的 Markdown 链接校验，覆盖尖括号链接及检索版的页内跳转。

## 安装与兼容

已有知识项目可继续使用现有文件，直接采用问答维护手顺。实际错答是否修复，由项目方在修正后的系统用原问法复跑。

```bash
git clone --branch v2.1.0 https://github.com/Ethereal-Space-one/code2kb-agent-toolkit.git
cd code2kb-agent-toolkit
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install .
code2kb --version
```

## English

The QA case maintenance procedure covers initial authoring and feedback about incorrect answers. Review candidate knowledge, retrieved evidence and live answers separately, then add confirmed cases to the existing module QA checks. Use the original question for regression checks and reserve unseen real questions for quality measurement. Existing projects can adopt the procedure with their current files. [English usage guide](https://github.com/Ethereal-Space-one/code2kb-agent-toolkit/blob/v2.1.0/docs/usage.en.md)

The 2.1.0 supplement validates static call matching and reference ownership during preflight and reuses fixed Git reads within each command. The public UniApp fixture uses one manifest read and one parse in `check` and `prepare --refresh`.
