## English

The QA case maintenance procedure covers initial authoring and feedback about incorrect answers. Review candidate knowledge, retrieved evidence and live answers separately, then add confirmed cases to the existing module QA checks. Use the original question for regression checks and reserve unseen real questions for quality measurement. Existing projects can adopt the procedure with their current files.
