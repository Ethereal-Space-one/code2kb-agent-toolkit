# Code2KB Agent Toolkit 2.4.0 有证据的控件行为与集合范围

发布日期 2026-11-16。

- **作者填写的控件规格**：可选 `c2kb-ui/0.1` 章节按稳定控件身份及范围区分同名按钮，记录显示、启用、忙碌、条件、触发、守卫、去向和反馈，引用已有已确认事实。
- **只读双版候选**：`render-ui-facts` 输出业务及研发片段。它不改写正文、审核或发布；条件与转换变化进入既有事实影响复核，历史发布保持不变。
- **可复现生命周期**：自编四控件例子覆盖空输入、等待守卫、正常返回、异常、用户重试、本地开关以及失效复核。固定事实和源码片段独立保留，测试不运行 Vue、设备、后端或回答模型。
- **集合范围参考**：既有 FACT/ENT、正文、审核和检索可以区分列表筛选、分页、跨页选择、本页全选、全部匹配、批量和导出目标。自编六条订单例子提供精确集合与改述回归题，不新增集合对象、解析器或通用工作流引擎。

## 兼容与升级

工程版本按向后兼容的可选功能增补升级为 2.4.0。基础知识文件、审核状态、发布清单和检索单元格式不变，没有 UI 章节的现有知识项目无需迁移或重发。

UI 扩展仅用于 `c2kb-file/1`。启用后必须使用 2.4+ 执行 `check`、`preflight`、`impact` 和后续准备发布；旧工具即使能读取该 Markdown，也不理解 UI 引用和变更依赖。历史 `0.8.3` 项目不启用时保持原行为，不自动迁移。详见[兼容矩阵](compatibility.md)。

## 使用边界

这不是自动按钮提取器、UI 测试框架或线上业务完成证明。作者仍须取证并独立复核条件与事实是否配对。`enabled` 不等于权限，忙碌不等于请求已送达，正常返回不等于持久化或业务完成。渲染的可读性和真实问答质量仍须复核；短语检索门禁不证明语义正确，`retrieval-query` 仍为 `answerability: not_assessed`。

## English

Release date: November 16, 2026.

An optional, authored `c2kb-ui/0.1` section links scoped controls, presentation dimensions, states, guarded transitions and feedback to existing verified facts. `render-ui-facts` returns business/engineering review candidates without editing, approving or publishing them. UI changes participate in existing fact-impact review.

A self-authored four-control fixture covers blank input, pending guards, return/failure, user retry and local dialog open/close. A separate bounded six-order example validates collection scope using existing facts and retrieval, without a collection schema or workflow engine. Public paraphrase questions and a separate answer key support reproducible retrieval and independent answer replay, not a production benchmark.

Existing projects without the optional section need no migration. UI-enabled projects require 2.4+ for validation and impact protection; older tools do not understand this extension even though the base format is unchanged. No automatic extraction, front-end execution, backend completion or final bot-answer quality is claimed.
