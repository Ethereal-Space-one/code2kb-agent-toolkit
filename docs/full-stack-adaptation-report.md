# 全栈与跨语言取证适配实施记录

对应[实施计划](full-stack-adaptation-plan.md)，基线为开源仓库 `1.2.0`、`83c171f`。本次自行编写通用参考、程序修改和公开夹具；按 1.2.0 后续补充交付，工程版本及文件协议未调整，已有发行标签保留原快照。

## 实现

| 需求 | 结果 |
| --- | --- |
| FS-01 | 新增全栈范围参考，涵盖仓库／worktree／子模块、检出与服务数量区分、非标准布局及依赖版本。可选定位索引只放在内部工作资料，复用既有事实 |
| FS-02 | 新增按需加载的场景参考，覆盖界面与服务契约、状态、异步与消息、原生资源和配置覆盖；修订 PHP、UniApp 的角色假设及 Java 特例。补充设计问答与静态对照的边界 |
| FS-03 | 复用 `--scope`，放行范围根及祖先中的默认过滤名称，保留范围内部过滤和原有安全限制。Adapter 规则版本为 `0.2`；输出格式、默认候选格式和 SDK 签名不变 |
| FS-04 | 双向关联通过条件不变；四类错误分别指出不存在的 ID 或缺少反向关联的列。模板与参考说明关联索引和直接调用图的区别 |

## 验证记录

- 针对性验证：11 项测试通过，覆盖默认及显式扫描、未知后缀、无后缀文件、非普通／二进制／非 UTF-8／大小与数量限制、固定提交不受工作区修改影响、CLI 输出及四类关联错误、多对多合法关联。
- [三个公开案例](../conformance/full-stack/README.md)已通过：使用十个自行编写的源码文件、分开的预期结果和业务答复，核对固定提交证据、双版发布、审计、检索评测及有限召回中的条件和未知。未执行服务、原生程序、容器或机器人模型。
- 语义对照由本次作者 AI 逐段阅读源码完成：分别保留导出权限与运行额度未知、受理／确认与完成的差异及契约不一致、失败分支未执行临时文件删除与部署未知。这不是独立验证者报告，也不构成所有语言的理解质量证明。
- 本地全量回归：Python `3.9.6` 下 255 项测试全部通过，包含既有审核、历史发布与检索相关回归。
- 公开候选快照检查：66 条规范编号与覆盖、4/4 一致性夹具、2/2 关系契约、版本边界、本地 Markdown 链接及公开内容扫描通过。候选不含工作区原有的未跟踪资料，扫描沿用项目本机配置的拒绝词，但不复制这些配置到产物。
- 既有合成检索规模检查 96/96 通过，仅证明该合成样本的规模与确定性；最小项目及公开源码接续演练通过，后者核对 10 个任务的恢复与溯源。
- 从公开候选快照离线构建并安装到独立临时目录，`code2kb --version` 与 `analyze-candidates --help` 通过；Python 编译和 `git diff --check` 通过。
- 本地验收使用 Python 3.9.6；Python 3.9–3.13 的远端结果以本次 PR 的[既有 CI](https://github.com/Ethereal-Space-one/code2kb-agent-toolkit/blob/v2.1.0/.github/workflows/ci.yml)记录为准。此补充不切换任何使用方知识库版本。

本次未引入语言白名单式的范围限制或统一 AST；未知文本的 L1 盘点不能等同于结构解析，静态发布与检索结果不能等同于线上行为。后续提交、CI 与发行按项目既有流程进行。
