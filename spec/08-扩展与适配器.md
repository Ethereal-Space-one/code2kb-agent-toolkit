# 扩展与适配器

适配器用于枚举特定技术栈的入口，扩展用于增加外部检查或项目特定敏感规则。

[Adapter 输出契约](../docs/adapter-contract.md)先报告固定提交的文件和源码候选，再由复核者把它们归类到下述稳定入口模型。L1 文件盘点、L2 确定结构与 L3 关系能力分别声明；仅有词法匹配或跨语言同路径时，关系保持 `candidate`，不能冒充已审核事实。业务版和研发版知识依然通过规格、证据及审核流程生成。

- **C2KB-EXT-001**：适配器输出必须回到统一入口模型，包含稳定入口 ID、类型、动作、模块、证据和状态。
- **C2KB-EXT-002**：适配器缺失或失败时必须显式登记覆盖缺口，禁止默认为范围完整。
- **C2KB-EXT-003**：外部自动审核检查必须使用 `external.*` ID；新策略审核须绑定已提交报告文件的路径、可复算摘要及与候选、模块、检查和结果相符的机器可读信封。
- **C2KB-EXT-004**：外部扩展禁止冒充参考实现内置检查。
- **C2KB-EXT-005**：项目可以增加 `sensitive_patterns`，但不得关闭私钥等基础高置信敏感信息检查。
- **C2KB-EXT-006**：第三方 Validator 或 Publisher 可以声明兼容，但必须公开其覆盖的规范编号和未实现项。

- **C2KB-EXT-007**：仅在选择启用[界面交互规格](../docs/ui-behavior-contract.md)时，须按 `c2kb-ui/0.1` 固定结构登记控件、状态与转换，引用本模块已有且已确认的事实与入口；结构、引用与条件变更进入既有影响复核，不能自动提升证据等级或发布批准。未启用的项目保持原流程。
